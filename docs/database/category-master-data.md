# 共通区分マスタデータ

[テーブル定義](01-master.md) / [共通ルール](00-common.md#共通区分参照) / [全体一覧](../database-design.md)

区分グループと区分値のマスタデータをまとめる。テーブル構造・型・制約は[テーブル定義](01-master.md)を参照する。group_id / value_idは先頭ゼロを保持した固定3桁の数字文字列として扱う。

## category_groups — 区分グループマスタ

共通区分定義として管理する対応は以下のとおり。group_idを利用箇所ごとにハードコードせず、この対応に基づき参照する。

| group_id | group_name | group_code |
| -------- | ---------- | ---------- |
| `001` | レア区分 | rarity |
| `002` | 限定区分 | limited |
| `003` | コラボ区分 | collaboration |
